# Call the Nest API directly from Next.js

Next.js renders initial reads through Server Components calling NestJS directly, while interactive Client Components call the same API with a verified Clerk Bearer token and Server Actions may adapt simple forms. Route Handlers are reserved for genuine protocol, aggregation, or server-secret needs rather than forming a duplicate BFF; authenticated data is uncached by default, and every explicit cache key includes the relevant Organization, User, filters, and authorization dimensions.

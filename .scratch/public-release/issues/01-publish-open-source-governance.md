# 01: Publish open-source governance

**What to build:** a contributor can understand the MIT template's license,
contribution path, security reporting route, semantic versioning, and migration
guidance without assuming clones update automatically.

**Blocked by:** Extensions 08 — Certify removal recipes and Extension isolation.

**Status:** ready-for-agent

- [ ] License, notices, contribution, code-of-conduct, and security-reporting materials are accurate and non-secret.
- [ ] Release notes and migration guidance distinguish template releases from cloned products.
- [ ] Documentation names known support and security limits honestly.

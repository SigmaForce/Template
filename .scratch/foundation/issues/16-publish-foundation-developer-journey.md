# 16: Publicar a jornada de desenvolvimento Foundation

**What to build:** uma pessoa sem contexto prévio clona o projeto e reproduz a jornada Foundation completa usando documentação, configuração e dados sintéticos seguros.

**Blocked by:** 15 — Aplicar os quality gates no CI.

**Status:** ready-for-agent

- [x] O guia explica pré-requisitos, instalação, configuração de desenvolvimento, startup, testes e troubleshooting comum.
- [x] Um comando de bootstrap prepara infraestrutura e seed sintético sem acessar ou copiar dados de produção.
- [x] A jornada documentada cobre autenticação, criação da Organization, Invitation, troca da Active Organization, Permissions e Membership Suspension.
- [x] A documentação explica limites entre web, API, worker, UI, contratos e configuração sem incentivar uma pasta compartilhada genérica.
- [x] O guia de customização cobre marca, tokens, matriz de Permissions e convenções de domínio.
- [x] O guia identifica claramente Commerce, Extensions e Public Release como fases futuras, sem apresentar stubs como funcionalidades prontas.
- [x] Um usuário novo consegue concluir a jornada documentada e todos os quality gates permanecem verdes.
